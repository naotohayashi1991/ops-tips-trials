# ops-tips-trials

他の開発者から教わった「無人で動く VPS 運用」の知見を、実際に試した記録です。

- 試すのはリスクの低いものだけです。
- 試験は本番から切り離した隔離環境（bubblewrap。システム領域は読み取り専用、書き込めるのは作業フォルダだけ、パッケージ導入なし）で行います。
- 本番への反映は、結果を見て別途判断します。
- 毎日 `trials/YYYY-MM-DD.md` に追記されます。

判定は「効果あり／一部効果あり／効果なし／判定不能」の4つです。効果がなかったものもそのまま載せます。

教えてくださった方のお名前や元の発言は、ご本人の了承を得ていないため載せていません。
